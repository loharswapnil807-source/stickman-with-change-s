    How to play

    1. Letters fall. Press the matching key before it crosses the red line.
    2. Hits build combo: jab → cross → kick → launcher → air x2 → slam.
    3. Miss = enemy hits you, −1 health. Wrong key = combo resets, no damage.
    4. Solo: Round 1 = 0:45, then +0:30 each round, faster falls. 5 health.
    5. Contest: two names, 45 seconds each on this device, higher score wins.
    6. Online: create a room, share the invite, race live 45s with identical letters.
    7. Pause: Esc or Shift+P (plain P is a game letter).
